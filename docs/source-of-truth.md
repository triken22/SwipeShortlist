## Jobs To Be Done

When I have a pile of options in a group chat, I want one simple voting link, so I can stop coordinating and get to one acceptable decision.

When I am asked to vote, I want each option reduced to the few facts that matter, so I can answer quickly without reading a thread.

When everyone has voted, I want one final recommendation, so I can send the decision and prevent more debate.

## Behavioral Constraints

- Time scarcity: every screen should reduce effort, not invite exploration.
- Octalysis: use scarcity/deadline lightly, ownership through private vote, social proof only after voting, and accomplishment at result reveal.
- Behavioral science: default action is one tap; avoid choice overload; prevent social conformity by hiding peer votes until after user action.
- Design philosophy: fewer surfaces, stronger hierarchy, visible progress, irreversible-looking finality only at the result screen.
